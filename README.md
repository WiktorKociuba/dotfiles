# My arch linux .config files
In this repo you can find my arch config files. I currently use matugen to generate the color pallete of my os. I use niri as my WM, waybar and SDDM. Most of the files are the config files for different applications that I use. Everything is nicely stored in coresponding folders, so if you want, take a look :3 Also, enjoy some screnshots :3
